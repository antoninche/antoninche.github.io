  • Prix « Nature & Informatique », Trophées NSI 2026“Nature & Informatique” prize, Trophées NSI 2026

    Défi Nature

    Recréation en Python du jeu de cartes Défis Nature, à trois, en terminale NSI. À chaque manche, on compare le poids, la longueur ou la longévité de deux animaux. Le moteur de jeu est séparé de l’interface Pygame, et des robots aux stratégies variées (hasard, statistiques, Monte-Carlo) s’affrontent sur des milliers de parties ; un module de simulations compare leurs résultats.

    A Python remake of the Défis Nature card game, built by a team of three in our final year of high school. Each round compares two animals by weight, length or lifespan. The game engine is separate from the Pygame interface, and bots with different strategies (random, statistics, Monte Carlo) play thousands of games against each other; a simulation module compares their results.

    Python, Pygame, NumPy, tests unitaires, unit tests

    A small school-grades platform inspired by PRONOTE, the software used in French schools: a teacher area (grades, class statistics, timetable, absences) and a student area (averages, rank, homework). Passwords are hashed with PBKDF2.

  • Tower Defense

    Un jeu de défense de tours en pixel art, écrit en Python avec Pyxel. Parti d’un prototype réalisé en six heures à la Nuit du Code, je l’ai repris pour en faire un jeu complet : quatre types de tours, quinze vagues, interface de jeu, système de vies et effets sonores générés par le code. Tout l’équilibrage (coûts, portées, dégâts, vagues) tient dans un seul fichier de réglages.

    A pixel-art tower defence game written in Python with Pyxel. It started as a prototype built in six hours at the Nuit du Code coding marathon; I then developed it into a complete game: four tower types, fifteen waves, an in-game HUD, a lives system and sound effects generated in code. All balancing values (costs, ranges, damage, waves) live in a single settings file.

    Python, Pyxel, exécutables Windows et macOS (PyInstaller, GitHub Actions)Python, Pyxel, Windows and macOS builds (PyInstaller, GitHub Actions)
